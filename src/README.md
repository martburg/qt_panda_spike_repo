# src

## Purpose

Python source tree (package code plus some development artifacts).

## Subdirectories

- `logs/` — Example/seed JSONL logs placed under `src/` for quick demos or tests.
- `steuerung3d/` — Main Python package implementing the Steuerung3D remake: core tick/engine, protocol boundary, adapters, and runnable apps.
- `steuerung3d.egg-info/` — Build metadata generated by packaging tools (setuptools). Not hand-edited.
